# Biblioteca API

API REST para una aplicación de gestión de biblioteca, construida con Express 5 y TypeScript.

## Requisitos

- Node.js compatible con las dependencias instaladas.
- npm.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

La API se inicia en `http://localhost:3000` por defecto. El puerto se configura mediante `PORT` en `.env`.

## Compilar y ejecutar

```bash
npm run build
npm start
```

## Endpoint inicial

- `GET /` — devuelve el estado y nombre de la API.
